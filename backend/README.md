# Backend - Gym System

## Sobre o projeto

O backend do Gym System é responsável por processar as informações do sistema da academia, realizar a comunicação com o banco de dados e atender às solicitações feitas pelo frontend.

## Funcionalidades

O backend será desenvolvido para permitir:

- Cadastro e gerenciamento de alunos.
- Cadastro e gerenciamento de professores e funcionários.
- Autenticação de usuários.
- Consulta e gerenciamento de exercícios.
- Criação, edição e consulta de treinos.
- Gerenciamento da agenda de presença.

## Estrutura da pasta

Os arquivos relacionados à lógica do servidor, às rotas e à comunicação com o banco de dados serão organizados nesta pasta.

## Banco de dados

O backend utilizará o banco de dados `sistema_gym`, responsável por armazenar as informações dos usuários, exercícios e treinos.

## Desenvolvimento

As funcionalidades serão implementadas gradualmente, conforme as tarefas definidas nas Issues do projeto.
